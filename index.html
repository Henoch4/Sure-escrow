Why SureEscrow

Freelance trust problem, solved by custody — not reputation.

🔐

Funds locked in code

The client transfers the full amount into the contract at deal creation. Neither party can withdraw it outside the milestone rules.

🎚️

Granular release

Each milestone is a separate amount. Ship phase 1, release phase 1 — the rest stays locked until you say otherwise.

⚖️

Escalation path

Either party can open a dispute; the contract's arbiter decides the split and the contract executes it in the same transaction.

How it works

Create, deliver, release — with a dispute button if things go sideways.

01

Create a deal

Client lists the freelancer and the milestone amounts; the full total is pulled into escrow immediately.

02

Release on delivery

After each accepted milestone, the client calls release(dealId, idx) — that slice goes straight to the freelancer.

03

Dispute if needed

Either party calls dispute; the arbiter resolves with a payout split, or the client cancels unstarted deals for a full refund.

Model

A deal is a fixed list of milestone amounts. createDeal pulls the entire total from the client into the contract; from then on money only moves along three paths:

release(id, i)      client only   →  milestone i's amount → freelancer
cancel(id)          client only   →  full refund (only if nothing released)
dispute(id)         either party  →  freezes deal
resolveDispute(id,payFreelancer)  arbiter only → splits remaining funds

Once every milestone is released, the deal auto-settles (active = false). Milestones are individually tracked — partial progress never endangers the locked remainder.
